Embedded HTML iframe

This is a fully self-contained HTML document embedded into the slide via an <iframe srcdoc>. It has its own CSS scope, its own scrollbar, and runs in a sandboxed origin — so it cannot reach the parent slide's window.

Why an iframe?

The slide's own DOM uses scrolly's CSS conventions. Authoring an interactive demo or a long-form HTML excerpt as an iframe means you can ship whatever HTML, CSS, and JavaScript you like — flexbox, custom fonts, scoped variables — without leaking into surrounding slide elements.

Scrolling

Scroll inside this box. The iframe captures wheel input, so the slide's own scroll behaviour stays put. Once you reach the top or bottom of this document, additional scroll propagates back up.

What works inside

  • Inline CSS in <style> blocks
  • Inline JavaScript in <script> blocks
  • data: URI images
  • External-CDN resources where allowed by the sandbox policy

What doesn't

Relative references inside the document. The base URL is about:srcdoc, so any src="logo.png" would look for about:srcdoc/logo.png and fail. Inline anything you need as a data: URI instead.

<img src="data:image/png;base64,..."/>

Sandbox

Scripts run, but in a unique origin — so window.parent is cross-origin and inaccessible. That's the default and usually what you want for the "embed an interactive demo" use case.

Filler text so the iframe genuinely overflows and the iframe-internal scrollbar shows up. The slide's own scrollbar is independent — it does not move when you scroll inside this box.
