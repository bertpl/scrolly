# Postscript

After the disclosure, the xz project was handed back to Lasse Collin, who audited and re-released the codebase.

- The 5.6.0 / 5.6.1 release tarballs were pulled from every mirror.
- The malicious m4 build scripts were removed and the build system simplified.
- GitHub restored the repository after the cleanup was verified.
- Distros rolled back to 5.4.x and rebuilt downstream packages.
- The project moved to a slower, more conservative release cadence.

The maintainer's own post-mortem is candid about the social-engineering pressure that preceded the handover — worth reading in full alongside the FAQ linked on the references slide.
