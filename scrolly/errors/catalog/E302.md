# E302 - Numeric width or height must be > 0

## Cause

A numeric `width:` or `height:` value is zero or negative. Sizes are
percentages of the viewport and must be positive.

## Example

```json5
{ markdown: "...", width: 0, height: 20 }
```

## How to fix

Use a positive numeric value, `"auto"`, or an animated form
(`{ keyframes: [...] }`).
