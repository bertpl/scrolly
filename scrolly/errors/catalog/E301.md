# E301 - Both width and height are "auto"

## Cause

An element has both `width: "auto"` and `height: "auto"`. At least
one dimension must be a numeric percentage or animated so the
auto-sized dimension has a reference to compute against.

## Example

```json5
{ markdown: "...", width: "auto", height: "auto" }
```

## How to fix

Give either `width` or `height` a numeric value: `width: 50`
(percent of viewport) or animate one of them.
