# E008 - Position entries must be integers

## Cause

A `position: [x, y]` entry contains a non-integer value (float, string,
boolean, etc.). The deck grid uses integer cell coordinates only.

## Example

```json5
{ slides: [{ id: "x", position: [0.5, 0], source: "x.slide.json" }] }
```

## How to fix

Use integer grid coordinates: `position: [1, 2]`.
