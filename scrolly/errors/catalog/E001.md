# E001 - JSON5 syntax error

## Cause

A deck or slide source file could not be parsed as JSON5. The parser
rejected the input syntactically before any schema checks ran.

## Example

```json5
{
  title: "My Deck"
  slides: []   // missing comma after the title value
}
```

## How to fix

Read the parser message for the offending location. Common causes:
missing commas between fields, unbalanced `{}`/`[]`, unquoted string
values. JSON5 allows trailing commas and unquoted keys, but not
unquoted string values.
