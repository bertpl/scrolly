# E602 - Element conversion cycle detected

## Cause

The element-compile machinery detected an infinite loop: an element
compiler emitted an element type that, after further compilation,
eventually produced the same type again along the same lineage.

## Example

A custom compiler transforms `ElementA → [ElementB]` while another
transforms `ElementB → [ElementA, ...]`.

## How to fix

This is an internal scrolly bug if you haven't registered a custom
compiler. If you have, audit the chain so it terminates in primitive
(renderer-handled) element types.
