# E003 - Missing required field

## Cause

A required field is absent. Deck files require `slides`; slide files
require `title` and `elements`; per-slide entries in a deck require
`id`, `position`, and `source`.

## Example

```json5
{ title: "My Deck" }   // missing 'slides'
```

## How to fix

Add the missing field. Run `scrolly schema deck` or `scrolly schema
slide` to see the full required shape for each file type.
