# E311 - Template element form invalid

## Cause

A `template` element authors both `template` (inline Jinja text) and
`template_file` (path), or neither.

## Example

```json5
{ template: "[]", template_file: "header.elements.json.j2", with: {} }
```

## How to fix

Author exactly one form: `template` for short in-place generation,
`template_file` for anything reused or long.
