# E002 - File must be a JSON object

## Cause

The file parses as valid JSON5 but its top-level value is not an
object — it's an array, string, number, or null.

## Example

```json5
[1, 2, 3]
```

## How to fix

Wrap the contents in `{ ... }`. Deck files need at least a `slides:`
field; slide files need at least `title:` and `elements:`.
