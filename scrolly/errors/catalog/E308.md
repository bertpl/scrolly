# E308 - Animated keyframes invalid

## Cause

An animated value's `keyframes:` list violates one of three rules:
fewer than 2 entries; scroll positions not strictly increasing; two
entries at the same scroll position.

## Example

```json5
{ opacity: { keyframes: [[100, 1], [50, 0]] } }   // not sorted by scroll
```

## How to fix

Provide at least two keyframes, sorted by scroll position, with no
duplicate scroll values.
