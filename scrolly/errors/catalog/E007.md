# E007 - Array has wrong number of elements

## Cause

A field expecting a fixed-length array got the wrong length. `position`
must be exactly two integers; `edges` entries must be exactly two
endpoint strings.

## Example

```json5
{ slides: [{ id: "x", position: [0, 0, 0], source: "x.slide.json" }] }
```

## How to fix

Trim or pad the array to exactly two elements.
