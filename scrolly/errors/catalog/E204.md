# E204 - scroll_range must be >= 0 or "auto"

## Cause

A slide's `scroll_range:` is a negative number. Allowed values are
non-negative numbers (explicit scroll length) or the literal string
`"auto"` (content-driven height).

## Example

```json5
{ title: "T", elements: [...], scroll_range: -100 }
```

## How to fix

Use `0`, a positive value, or `"auto"`. `"auto"` is the default and
fits the scroll range to the slide's content height.
