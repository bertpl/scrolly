# E504 - Slide source filename has unknown suffix

## Cause

A slide entry's `source:` filename ends in a suffix that no registered
slide type recognises. The supported suffix is `.slide.json`.

## Example

```json5
{ slides: [{ id: "x", position: [0, 0], source: "x.slide.txt" }] }
```

## How to fix

Rename the file to use `.slide.json` and update the `source:` field.
