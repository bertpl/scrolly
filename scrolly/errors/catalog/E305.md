# E305 - image_sequence needs at least 2 entries

## Cause

An `image_sequence` element has fewer than 2 frames. The element type
exists to crossfade between successive frames, so a single-frame
sequence is meaningless.

## Example

```json5
{ image_sequence: ["a.png"], frame_distance: 100, hold: 50 }
```

## How to fix

Add more frames to the sequence, or replace the element with a plain
`image:` element if a single frame is all you need.
