# E306 - image_sequence timing constraint violated

## Cause

One of the timing constraints on `image_sequence` is violated: `hold`
must be `> 0`; `frame_distance` must be strictly greater than `hold`
(to leave room for a non-zero crossfade); `fade_in` and `fade_out`
must be `>= 0`.

## Example

```json5
{ image_sequence: ["a.png", "b.png"], frame_distance: 50, hold: 50 }
// hold equals frame_distance — no room to crossfade
```

## How to fix

Adjust the timings so `frame_distance > hold > 0` and `fade_in,
fade_out >= 0`.
