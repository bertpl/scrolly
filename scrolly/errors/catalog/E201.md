# E201 - At least one element required

## Cause

A slide has an empty `elements: []` list. Every slide must contain at
least one element (markdown, html, image, etc.).

## Example

```json5
{ title: "Empty", elements: [] }
```

## How to fix

Add at least one element. The simplest is a markdown block:
`elements: [{ markdown: "# Hello" }]`.
