# E601 - No element compiler or renderer registered

## Cause

A slide contains an element of a type that no registered renderer or
compiler handles. This usually means the element JSON doesn't carry
the discriminating field for any built-in element type.

## Example

An element object with no recognised type field — no `markdown:`,
`html:`, `image:`, `image_sequence:`, `iframe_html:`, or `mermaid:`.

## How to fix

Check the element JSON against `scrolly schema slide`. Each element
must include the field that names its type.
