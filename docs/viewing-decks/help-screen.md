# Help screen

Every built deck carries a built-in help screen, so readers can learn
the controls without leaving the presentation.

## Opening it

Press **`h`** or **`?`**, or click the **`?`** icon in the top-right
chrome. Dismiss it with **Ok**, by clicking outside it, or by pressing
**`h`** or **Escape**.

## What's inside

The help screen has three sections:

- **About** — the deck's scrolly version, author, and a link to the
  project.
- **Help** — the navigation and keyboard shortcuts (the same set listed
  in [Navigation & shortcuts](navigation.md)).
- **Statistics** — counts of slides, edges, and assets, plus the
  output's file size and how much compression saved (see
  [Output & bundling](../concepts/output-and-bundling.md)).

The statistics panel is a quick way to understand a deck's size
breakdown — useful when deciding whether an asset is worth its weight.
